# Mencraft CRUD - Visual Dipertahankan
- Frontend pelanggan tetap memakai visual Mencraft sebelumnya.
- Harga produk sekarang memakai satu harga patokan (`price`), bukan harga minimum-maksimum.
- CRUD produk: tambah, lihat, edit, hapus, aktif/nonaktif.
- CRUD pesanan: lihat, update status, hapus.
- Setiap aksi CRUD pada halaman admin memiliki checkbox konfirmasi dan pemberitahuan jika belum dicentang.
