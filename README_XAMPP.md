# Mencraft + CRUD + Satu Harga
1. Ekstrak folder ke C:\xampp\htdocs\mencraft-final-crud
2. Buat database `mencraft_db` di phpMyAdmin.
3. Import `database/mencraft_db.sql`.
4. Periksa `config/database.php`.
5. Website: http://localhost/mencraft-final-crud/
6. Admin CRUD: http://localhost/mencraft-final-crud/admin/
